# Arena of the Deep

A small, original 2D arena-survival prototype inspired by wave-based combat. It runs directly in a modern browser and uses simple canvas-drawn placeholder art.

## Run

Open `index.html` in a browser. No install or build step is required.

## Controls

| Key | Action |
| --- | --- |
| Left / Right | Move |
| Up / Down | Look up or down; aim attacks |
| Z | Jump; press again in the air for a double jump |
| X | Nail attack |
| A (tap) | Cast a projectile |
| A (hold) | Focus to spend SOUL and heal |
| F | Quick cast |
| C | Dash |
| D | Dream Nail a nearby enemy to gain SOUL |
| S (hold, release) | Charge and launch a super dash |
| Tab | Arena map |
| I | Field notes |
| Esc | Pause; restart after defeat |

Defeat enemies to gather SOUL, use spells and healing strategically, and survive increasingly large waves.
